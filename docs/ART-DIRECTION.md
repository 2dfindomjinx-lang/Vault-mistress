# Court visual guide

Keep Principessa, the dark burgundy setting and warm gold typography as the identity. Use the existing character references for her face, hair, line weight and proportions. Frame the face clearly; keep light warm, shadows burgundy, and backgrounds quiet. Export transparent character cutouts without edge halos. Avoid changing established collectible art as part of UI maintenance.

Use court-panel for primary sections, court-feature-card for individual objects and a subtle inset background for supporting details. Use the 4/8/12/16/24 spacing scale. Reserve gold for status and primary headings; burgundy for main actions; bright pink for limited highlights. Body and actionable labels should generally be at least 14px and 12px respectively. Tiny decorative labels must never carry the only instruction.

Keep the large character stage on Home. Feature screens use a compact chamber heading and account bar. Mobile uses four main destinations plus a complete directory, with a single chat launcher above the bottom menu. Check keyboard focus, reduced motion and 390px width when adding any floating element.
